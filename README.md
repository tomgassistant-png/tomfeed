# TomFeed (curiosities)

Static curiosities feed published on GitHub Pages.

| Host | URL |
|------|-----|
| **GitHub Pages** | https://tomgassistant-png.github.io/tomfeed/ |

The daily build reads `curiosities.md`, updates `feed.json` and `ever-seen.json`, and regenerates `index.html` with `python3 generate.py`.

Interests: [`curiosities.md`](curiosities.md).
